# Yash Thorat - Developer Portfolio

A premium, modern, and responsive developer portfolio website with 5 color themes, dark/light mode, and complete animations.

## Features

- ✅ 5 Premium Color Themes (Gold, Blue, Purple, Emerald, Red)
- ✅ Dark/Light Mode Toggle
- ✅ Theme Persistence with LocalStorage
- ✅ Full Responsive Design (320px to 1920px)
- ✅ Typing Animation
- ✅ Scroll Reveal Animations
- ✅ Animated Counters
- ✅ Skill Progress Bars
- ✅ Project Filtering
- ✅ Contact Form with Validation
- ✅ Sticky Navbar with Active Indicator
- ✅ Scroll Progress Bar
- ✅ Professional Preloader
- ✅ Floating Social Icons
- ✅ Back to Top Button
